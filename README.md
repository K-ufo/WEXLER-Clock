# WEXLER Clock
Перекидные часы для Android 4.1+ (API 16). Горизонтальный режим, 24-часовой формат, без интернета.

GitHub Actions → Build WEXLER Clock APK → артефакт WEXLER-Clock-APK.

Экран не гаснет во время работы приложения. Не оставляйте старый планшет без присмотра на постоянной зарядке, особенно при нагреве или неисправной батарее.
